# ATmega32-Traffic_light_project
Traffic light using microcontroller ATmega32 (code/drives/circuit)
# Project Overview
Traffic lights are everyday objects that perform the critical task of preventing accidents and maintaining order. This project recreates a traffic light control system using an ATmega32 microcontroller, developed as a task for the IMT-Creativa course under the guidance of [Mention Name].

# Technical Highlights

    Language: C

    Microcontroller: ATmega32

    Architecture: Implemented a layered software architecture (MCAL, HAL, APP) to ensure the system is modular, easily modifiable, and simple to debug.

    Drivers Developed: DIO_driver, LED_driver, and 7_segment_driver.

    Tools Used: Eclipse (Environment setup and .elf generation) and Proteus (Circuit simulation).

    Key Concepts: Embedded systems design, COTS (Commercial Off-The-Shelf) integration, and hardware-software interfacing.
